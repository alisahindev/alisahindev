## What I build

- **Realtime media.** RTSP ingest to WebRTC / LL-HLS playback for multi-tenant camera monitoring, built to scale past 500 cameras.
- **AI products.** Provider-agnostic LLM features behind edge functions (Gemini, Claude), cost modelled per request, and realtime voice.
- **Platforms.** [Tessera](https://github.com/alisahindev/tessera), an ESM-first microfrontend platform with its own protocol, runtime and linker.
- **Monorepos that stay fast.** Turborepo / pnpm / Bun workspaces sharing schemas across Expo, Next.js and the API.
- **Games.** Native game loops on SpriteKit and Canvas, plus browser games with zero dependencies.
